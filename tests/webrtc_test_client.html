mezon-sfu WebRTC test client

No signaling server exists yet, so this builds the SDP answer by hand from the server's logged ICE/DTLS credentials. Open this in two tabs to test the actual media relay between two peers.

Server credentials

Copy these from the mezon-sfu process log at startup (local ICE credentials: ufrag=... pwd=... and cert fingerprint sha-256 ...).

Serve this file over http://localhost (e.g. python3 -m http.server from the tools/ directory) rather than opening it directly as file:// -- some browsers only allow microphone access from a secure context.
